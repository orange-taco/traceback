1 고객 → Netlify
화면을 열고 회원 요청을 보냅니다
  • Netlify는 React Router 화면을 제공합니다.
  • 회원 API 요청은 같은 사이트 주소로 보내므로 고객에게 서버 주소가 따로 보이지 않습니다.
2 Netlify → EC2
회원 요청만 AWS의 Nginx로 전달합니다
  • Netlify rewrite/proxy가 회원 경로를 EC2로 넘깁니다.
  • Nginx는 HTTPS와 원래 호스트 정보를 보존해 Docker의 Django로 전달합니다.

이메일과 카카오를 함께 쓰는 기준

중복 회원은 만들지 않음
이메일 확인 완료 → 카카오

같은 이메일이면 기존 비밀번호를 유지하고 카카오를 같은 회원에 연결합니다.

둘 다 사용
이메일 미확인 → 카카오

카카오가 이메일 소유를 확인하면 연결하되, 선점자가 만든 기존 비밀번호는 무효화합니다. 비밀번호 찾기로 새 비밀번호를 만들 수 있습니다.

소유자 보호
카카오 가입 → 이메일 가입

같은 이메일로 새 회원을 다시 만들지는 않습니다. 비밀번호 찾기를 거치면 기존 한 계정에서 이메일 로그인도 사용할 수 있습니다.

중복 가입 차단
첫 카카오 로그인인데 이메일 확인 불가

카카오가 확인한 이메일이 없으면 실제 이메일 소유자인지 증명할 수 없습니다. 별도 이메일 입력으로 우회하지 않고 회원 생성을 중단합니다.

가입하지 않음
이미 연결된 카카오 재로그인

과거에 연결된 카카오 회원번호가 일치하면 같은 사람임을 확인할 수 있습니다. 이번 응답에서 이메일이 빠져도 기존 회원으로 로그인합니다.
