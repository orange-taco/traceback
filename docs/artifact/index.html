이 학습 사이트는 어떻게 공개되나요?

저장소에 HTML 파일이 있어도 공개 사이트는 자동으로 생기지 않습니다. 게시 작업이 실행되고 성공해야 URL에서 읽을 수 있습니다.

① 문서가 게시 브랜치에 도착TRACEBACK: PR을 development에 병합
② Pages 작업 성공artifact-pages.yml이 문서·이미지를 업로드
③ 공개 URL 확인orange-taco.github.io/traceback/에서 목차 열기
첫 공개 전에 URL이 404였던 이유는?

2026-10-04 기준 게시 workflow는 PR 브랜치에만 있었습니다. 이 저장소는 development push에서 Pages를 게시하도록 설정했고 github-pages 환경도 그 브랜치만 허용합니다. PR의 Quality/Test 성공은 Pages 게시 성공을 뜻하지 않습니다. 병합 뒤 Pages 실행 결과와 실제 URL을 확인해야 합니다. API 서버의 ECR 이미지 빌드·EC2 배포는 별도 workflow이므로 Pages 404와 원인이 다릅니다. 게시 workflow 원문
