START · SYSTEM GUIDETRACEBACK 전체 구조와 CI/CD

고객 요청과 코드 배포의 큰 지도를 본 뒤 인증·워크플로 원문까지 이어집니다.

 01 · ACCESSSSH·SSM으로 EC2 접속

일반 네트워크 연결, AWS 신원과 권한, 로컬 터미널 접속을 구분합니다.

 02 · DEPLOY개발 서버 첫 배포

GitHub Actions에서 ECR·EC2·RDS까지 이어지는 설정 순서와 아직 막힌 지점을 봅니다.

 03 · ADDRESS서버 IP와 도메인

유동 IP·Elastic IP를 비교하고, 도메인 등록과 DNS 관리를 분리해 이해합니다.

 04 · DNS주소를 입력한 뒤 일어나는 일

브라우저가 DNS를 통해 IP를 찾고 HTTPS 서버에 연결하는 경로를 따라갑니다.

문서는 공개 학습 자료입니다. TRACEBACK의 실제 설정 상태는 각 문서에 표시된 확인 날짜를 기준으로 읽으세요.
