Kakao-only 계정 삭제

계정 삭제는 provider 연결 해제와 별도 endpoint입니다. Kakao 연결 해제가 성공한 뒤에만 로컬 계정을 정리합니다.

01 · 시작

사용자 브라우저

사용자가 “계정 삭제”를 누릅니다.

DELETE /accounts/delete
02 · 진입점

AccountDeletionView

로그인과 CSRF를 확인하고 삭제 서비스를 호출합니다.

apps/accounts/views.py
03 · 원격 먼저

unlink_kakao_user()

서버의 Kakao Admin Key로 동의 철회를 요청합니다.

apps/accounts/providers.py
04 · 외부 확인

Kakao API

성공한 사용자 ID를 반환합니다. 이미 끊겼으면 -101도 성공으로 봅니다.

POST /v1/user/unlink
05 · 로컬 정리

우리 DB + 세션

사용자를 익명화·비활성화하고 연결·이메일·세션을 정리합니다.

apps/accounts/services.py · atomic()

실패하면: Kakao 오류는 503 provider_unavailable로 응답하고 로컬 익명화는 시작하지 않습니다.

Email + Kakao 연결 해제

이 경로는 계정 삭제가 아니라 Kakao 연결만 해제합니다. 이메일 로그인은 유지됩니다.

01 · 시작

사용자 브라우저

사용자가 “Kakao 연결 해제”를 누릅니다.

DELETE /_allauth/browser/v1/account/providers
02 · 검증

allauth Headless

provider와 account를 확인하고 계정 상태를 검증합니다.

DeleteProvider · Input.clean()
03 · 정책

SocialAccountAdapter

Social-only 계정의 password 조건을 확인합니다.

apps/accounts/adapters.py
04 · 원격

unlink_kakao_user()

Kakao 동의를 철회합니다. -101은 이미 목표 상태입니다.

Admin Key POST
05 · 완료

SocialAccount 삭제

원격 성공 뒤 우리 DB에서 Kakao 연결 행만 삭제합니다.

connect.disconnect()

Social-only 계정이면: allauth가 400 no_password를 반환하며 Kakao 연결은 유지됩니다.

01Remote state first

Kakao 동의철회는 우리 DB transaction으로 되돌릴 수 없는 외부 변경입니다.

02-101 is idempotent success

이미 연결이 끊겼다면 목표 상태에 도달한 것이므로 HTTP 400이어도 계속 진행합니다.

03Local state is atomic

원격 성공 뒤 User·SocialAccount·EmailAddress·UserSession을 한 transaction으로 정리합니다.
