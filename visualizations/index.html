TRACEBACK · Phase 0 guide

흐름을 보고, 코드를 따라 읽기

현재 구현된 인증과 배포 경로를 실제 파일에 연결했습니다. 주문·결제·출고는 아직 계획 단계로 구분했습니다. 처음에는 전체 지도부터, 배포가 궁금하다면 CI/CD부터 읽으세요.

① 전체 구조구현 상태와 계획 구분→② 실행 흐름인증 또는 CI/CD→③ 코드 지도파일별 입력·판단·결과
01 · System

전체 구조

고객 흐름, 현재 구현 범위, 다음 Phase를 한눈에 봅니다.

 02 · Runtime

인증 흐름

브라우저 요청부터 allauth, TRACEBACK 코드, DB 상태 변경까지 따라갑니다.

 03 · Delivery

CI/CD 흐름

PR 검증, 개발 배포, 운영 승격을 분리해서 보고 세 가지 SHA를 이해합니다.

 04 · Source

코드 지도

구현 파일과 배포 파일을 입력·판단·결과 순서로 읽고 원본으로 이동합니다.

실제 AWS 배포는 아직 검증되지 않았습니다. GitHub development Environment의 배포 변수와 AWS 리소스 설정은 별도 작업입니다.
